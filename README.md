# Train Your Brain

A 3-day interactive experience by Danya Collyer. Static site: `index.html` (no build step).

Deploy on Vercel: import this repo, Framework Preset "Other", no build command.

Video links and the guide download link are set near the top of the `<script>` in `index.html` (`VIDEO_URLS` and `GUIDE_URL`).
